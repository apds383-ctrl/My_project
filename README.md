# Наш первый сервис

Готовый FastAPI сервис (версия 0.1.0). Реализованы эндпоинты для проверки статуса, получения информации о приложении и работы с книгами.

## 🚀 Быстрый старт (для локальной разработки)

Этот режим предназначен для удобной разработки: сервер будет автоматически перезагружаться при изменении кода.

1. **Создай виртуальное окружение и установи зависимости:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
   pip install -r requirements.txt
(Опционально) Настрой переменные окружения: Для работы эндпоинта /info создай файл .env в корне проекта:

env
APP_NAME=Учебный сервис
APP_AUTHOR=Разработчик
Если файл не создать, сервис использует значения по умолчанию.

Запусти сервер:

bash
python -m uvicorn app_final:app --reload --host 0.0.0.0 --port 8000
Проверь работу:

Приложение: http://127.0.0.1:8000/
Swagger UI (документация): http://127.0.0.1:8000/docs
Проверка данных: http://127.0.0.1:8000/info
☁️ Запуск в CI/CD и Production
Для автоматического тестирования (GitHub Actions) или деплоя на сервер обязательно используй команду без флага --reload:

bash
python -m uvicorn app_final:app --host 0.0.0.0 --port 8000
⚠️ Важно: В пайплайнах переменные окружения (APP_NAME, APP_AUTHOR) должны передаваться через настройки репозитория, а не через файл .env, который обычно игнорируется в git.

📋 Доступные эндпоинты
Метод	Путь	Описание
GET	/	Проверка работоспособности ({"message": "Сервис работает"})
GET	/version	Версия приложения ({"version": "0.1.0"})
GET	/health	Health-check ({"status": "ok"})
GET	/hello	Приветствие с параметром name
GET	/info	Метаданные (зависит от переменных окружения)
GET	/books	Список книг
GET	/books/{id}	Книга по ID
🧪 Тестирование
Для запуска тестов (если они есть):

bash
pytest
📝 О файлах проекта
app_final.py — основной файл приложения (готовый вариант).
app.py — шаблон для выполнения учебных заданий (может содержать заглушки).
examples/ — папка с промежуточными версиями кода.
.env — файл для локальных переменных окружения (не коммить в git).
